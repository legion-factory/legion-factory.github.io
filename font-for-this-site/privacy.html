Privacy Policy — Font For This Site

Last updated: 2026-10-19

Font For This Site changes the font family on websites you turn on. It does not collect, transmit, sell, or share personal data. There is no account, no analytics, and no advertising.

Contact: ppo.viktorov.aa@gmail.com

What is stored

The only stored data is the font rule you save. It stays in this browser, in the extension's local storage (chrome.storage.local). A rule is the site origin (scheme, host, and port), the font name you entered, whether the rule is on, and the time of the last change.

Rules are not synced to other devices and are not sent to a server. The extension does not use chrome.storage.sync.

What is read and then discarded

  • When you open the popup, the extension reads the address of that tab so it can show the site. It does not read other tabs.
  • On an http or https page it also checks the document type, only to see whether the page is a PDF. It does not read the page text.
  • It reads the names of fonts installed on the computer to fill the suggestions in the popup. That list is not stored.
  • On a page where a rule is on, it reads the font family already used by elements, including inline font settings, so code, monospace text, and common icon fonts can be left alone, and so an inline value it replaced can be put back.

None of these reads are stored or sent anywhere.

Sites and permissions

At install, the extension is not given access to websites. When you press Apply or turn a site on, Chrome asks for that host only. The pattern Chrome grants covers every port on that host, because a Chrome host pattern cannot name a port. The font is still applied only to origins you turned on.

The extension cannot change chrome:// pages, PDF documents, or the Chrome Web Store. It asks for nothing from those pages and does not save a rule from them.

Incognito

If you allow the extension in incognito, Chrome runs it in spanning mode. The same on-device rules apply. The extension cannot tell an incognito tab from a normal tab and does not keep a list of which tabs were incognito.

Remote code

All code is in the extension package. The extension does not download or run code from the network, and it does not load remote fonts, scripts, or styles for itself.

Deleting data

Reset site deletes that site's rule and removes the host permission when no other enabled site still needs the same host. Turning the switch off keeps the rule disabled and leaves the host permission in place. Uninstalling the extension deletes the remaining rules and permissions.

Children

The extension is not directed at children and does not ask for age or any other profile.

Кратко по-русски

Font For This Site меняет только семейство шрифта на тех сайтах http и https, которые вы включили. Персональные данные не собираются, не передаются и не продаются. Аккаунта, аналитики и рекламы нет.

На устройстве хранится только правило: источник (схема, хост и порт), имя шрифта, включено или нет, время изменения. Оно лежит в локальном хранилище расширения и на другие устройства не копируется.

При открытии окна читается адрес этой вкладки и, для страницы http(s), тип документа — чтобы не трогать PDF. Текст страницы не читается. Список установленных шрифтов нужен только для подсказок и не сохраняется. На включённом сайте читается font-family элементов, чтобы не менять код, моноширинный текст и значки и чтобы вернуть подменённое встроенное значение. Эти чтения никуда не отправляются.

Доступ к сайтам при установке не выдаётся. Chrome спрашивает его для одного хоста, когда вы нажимаете Apply. Страницы chrome://, PDF и Chrome Web Store не меняются. В режиме инкогнито, если расширение там разрешено, действуют те же локальные правила; отдельный журнал инкогнито не ведётся.

Код расширения не загружается из сети. «Reset site» удаляет правило сайта и снимает доступ к хосту, если он больше не нужен. Удаление расширения стирает остальные правила.
