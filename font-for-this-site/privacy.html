Privacy Policy — Font For This Site

Last updated: 2026-10-30 (version 0.1.3)

Font For This Site changes the font family, and optionally the text size and line spacing, on websites you turn on. It does not collect, transmit, sell, or share personal data. There is no account, no analytics, and no advertising.

Contact: ppo.viktorov.aa@gmail.com

What is stored

Everything the extension stores stays in this browser, in the extension's local storage (chrome.storage.local):

  • Site rules. A rule is the site origin (scheme, host, and port), the font name you entered, the text size and line spacing if you set them for that site, whether the rule is on, and the time of the last change.
  • Pending per-site choices. When Chrome asks you for access to a site, the popup can close. The font you picked for that site is kept as a pending choice (origin, font name, host pattern, time) until you allow or deny access, and it expires after a short time. It is deleted when it is applied, denied, or expired.
  • Recent fonts. A short list (up to 8) of font names you used recently, shown only as suggestions in the font field. It contains font names only, no sites.
  • Settings. Your light or dark theme choice.

None of this is synced to other devices or sent to a server. The extension does not use chrome.storage.sync.

What is read and then discarded

  • When you open the popup, the extension reads the address of that tab so it can show the site. It does not read other tabs.
  • On an http or https page it also checks the document type, only to see whether the page is a PDF. It does not read the page text.
  • It reads the names of fonts installed on the computer to fill the suggestions in the popup. That list is not stored.
  • On a page where a rule is on, it reads the font family already used by elements, including inline font settings, so code, monospace text, and common icon fonts can be left alone, and so an inline value it replaced can be put back.

None of these reads are stored or sent anywhere.

Sites and permissions

At install, the extension is not given access to websites. When you pick a font for a site, or turn a site back on in the All sites page, Chrome asks for that host only. The pattern Chrome grants covers every port on that host, because a Chrome host pattern cannot name a port. The font is still applied only to origins you turned on.

The extension cannot change chrome:// pages, PDF documents, or the Chrome Web Store. It asks for nothing from those pages and does not save a rule from them.

Incognito

If you allow the extension in incognito, Chrome runs it in spanning mode. The same on-device rules apply. The extension cannot tell an incognito tab from a normal tab and does not keep a list of which tabs were incognito.

Remote code

All code is in the extension package. The extension does not download or run code from the network, and it does not load remote fonts, scripts, or styles for itself.

Deleting data

Reset site, or Delete in the All sites page, deletes that site's rule and pending choice and removes the host permission when no other enabled site still needs the same host. Turning a site off in the All sites page keeps the rule disabled and leaves the host permission in place. Uninstalling the extension deletes all stored data and permissions.

Children

The extension is not directed at children and does not ask for age or any other profile.

Кратко по-русски

Font For This Site меняет семейство шрифта (и, если вы задали, размер текста и межстрочный интервал) только на тех сайтах http и https, которые вы включили. Персональные данные не собираются, не передаются и не продаются. Аккаунта, аналитики и рекламы нет.

Всё хранится только в локальном хранилище расширения (chrome.storage.local) и никуда не отправляется и не синхронизируется: правила сайтов (источник — схема, хост и порт; имя шрифта; размер текста и межстрочный интервал, если заданы; включено или нет; время изменения), отложенный выбор шрифта для сайта на время запроса доступа Chrome (удаляется после применения, отказа или истечения срока), короткий список недавних шрифтов (только имена, до 8) для подсказок и выбранная тема.

При открытии окна читается адрес этой вкладки и, для страницы http(s), тип документа — чтобы не трогать PDF. Текст страницы не читается. Список установленных шрифтов нужен только для подсказок и не сохраняется. На включённом сайте читается font-family элементов, чтобы не менять код, моноширинный текст и значки и чтобы вернуть подменённое встроенное значение. Эти чтения никуда не отправляются.

Доступ к сайтам при установке не выдаётся. Chrome спрашивает его для одного хоста, когда вы выбираете шрифт для сайта. Страницы chrome://, PDF и Chrome Web Store не меняются. В режиме инкогнито, если расширение там разрешено, действуют те же локальные правила; отдельный журнал инкогнито не ведётся.

Код расширения не загружается из сети. «Сбросить сайт» или «Удалить» на странице «Все сайты» удаляет правило сайта и снимает доступ к хосту, если он больше не нужен. Удаление расширения стирает все сохранённые данные.
