English

Save Tabs - Session Saver is a Chrome extension by Legion Labs that saves and restores the tabs in the current window on your device. This policy describes exactly what version 1.0.1 of the extension does with data. Earlier development builds used the name Named Window Tabs; this policy applies to the same extension.

The extension has no account system. A short public page for this policy is published at https://legion-factory.dev/save-tabs/privacy.html.

Data the extension handles

When you save a named session, when you keep a snapshot as a named session, or when an automatic snapshot is taken, the extension reads the tabs in that window only and stores:

  • a random session or snapshot id created on this device (this is not an account id or a user id)
  • for a named session, the session name you enter, at most 200 characters, with invisible and bidirectional-override characters removed
  • each tab’s URL as the browser reports it, or the tab’s pending URL if the address has not loaded yet
  • each tab’s title, at most 300 characters, with the same invisible characters removed; an empty title is stored as “Untitled”
  • whether the tab is pinned
  • the tab’s position in the window
  • if the tab belongs to a tab group, a local group id, and that group’s name, color, and collapsed state
  • optionally the window’s position and size, so a restore can reopen a window
  • the time the session or snapshot was saved

Automatic snapshots are taken when a window closes and about every five minutes, unless you turn them off in settings. The extension keeps the latest five automatic snapshots. You can delete a single automatic snapshot. Keeping a snapshot copies it into a named session; the snapshot itself stays in the automatic list until it is replaced or deleted. Named sessions are not part of that five.

A short local recovery flag may be stored if Chrome did not close cleanly, so the popup or the side panel can offer to restore the latest snapshot. Theme, language, whether automatic snapshots are on, whether the toolbar icon opens the popup or the side panel, and whether the Chrome Web Store rating prompt is postponed or dismissed are also stored on the device.

The extension does not read Chrome’s browsing history and does not store a separate visit time for each page. It does not read page text, cookies, passwords, form fields, or site icons.

Addresses that use the schemes javascript:, data:, vbscript:, and blob: are discarded and are not stored. That includes an address that becomes one of those schemes only after tab, carriage-return, and line-feed characters are removed. An address longer than 32,768 characters is not stored. A tab with no address is stored with an empty address and is not reopened. Other addresses in the window, including browser-internal pages, are stored. When you restore a session, the extension reopens http, https, and file addresses, a saved New Tab page, and about:blank. Any other stored address stays in the session and is not opened. Pages such as chrome:// are remembered but cannot be reopened.

A URL or title can still contain personal information, including a page you were signed into and a token a site put in the address. The extension keeps that URL string. It does not take the token out of the URL, and it does not send the URL anywhere.

If a stored session contains a blocked address, that tab is removed from the stored session. If every address in a stored session is blocked, that session is removed. Two stored sessions that share one id are kept as one session.

A new save or import is refused when that new session would hold more than 2000 tabs, or when it does not fit in local storage. There is no fixed cap on the number of named sessions. A session that is already stored with more than 2000 tabs is kept as it is. The extension does not delete stored sessions to make room.

You can export a JSON backup of sessions and snapshots and import that file back. You can also import a OneTab list or a Session Buddy JSON backup. Import reads only the file you choose. It merges new sessions and skips duplicates and invalid entries. Nothing is uploaded.

Where data lives

Sessions, snapshots, and the settings above are stored in chrome.storage.local in your Chrome profile. The extension does not use chrome.storage.sync. A short-lived copy of the tabs in each open window may also be kept in chrome.storage.session so an automatic snapshot can be taken when that window closes; Chrome clears session storage when the browser session ends. This data is not sent to the developer or to any other server. The extension does not include analytics, ads, or crash reporting, and its own code does not make network requests.

Version 1.0.1 can show the same on-device library in Chrome's side panel as in the popup. A setting stored on the device chooses whether the toolbar icon opens the popup or the side panel. The side panel does not send data anywhere.

Restoring a session asks Chrome to open the saved addresses as ordinary tabs. Chrome then loads those pages in the usual way. That is the browser opening a page you asked to reopen, not the extension uploading the session.

Export writes a JSON file on your computer only when you click Export. Import reads a JSON file only when you choose one. Neither action uploads the file. If you later send that file yourself, that happens outside the extension.

Incognito

The extension does not run in incognito until you allow it on chrome://extensions. When you allow it, incognito uses a separate store (incognito: "split"). A session or snapshot saved in an incognito window stays in that incognito session and is not copied into your regular profile. Chrome deletes that store when the incognito session ends.

Permissions

  • tabs — read the URL, pending URL, title, pinned state, position, and tab-group membership of tabs in the window you save or that is snapshotted automatically, and reopen those tabs on Restore. The extension reads those tabs in the current window when you save, when an automatic snapshot is taken, and when it restores a session. It does not inject scripts into pages and does not use the history, cookies, or scripting APIs.
  • storage — keep sessions, snapshots, and settings in chrome.storage.local on the device. Sync storage is not used.
  • unlimitedStorage — so the on-device library is not cut at 10 MB.
  • alarms — the five-minute window snapshot.
  • tabGroups — save and restore a tab group’s name, color, collapsed state, and membership.
  • sidePanel — show the same on-device library in Chrome's side panel. A local setting chooses whether the toolbar icon opens the popup or the side panel.

The extension does not request host permissions or permission to run remote code. There is no content script. It does not request sessions, history, or downloads.

How long data is kept

Named sessions stay until you delete them in the popup or the side panel, or until you remove the extension. Automatic snapshots stay until they are replaced by newer snapshots (the latest five are kept), until you delete one, or until you remove the extension. Chrome deletes the extension’s local storage on uninstall. Incognito sessions and snapshots end with the incognito session.

If a save or import does not fit in local storage, the extension leaves the sessions already stored in place and shows an error. It does not apply a 10 MB cap of its own.

Sharing

The developer does not sell this data, does not transfer it to third parties, and does not use it for advertising, creditworthiness, lending, or any purpose other than saving, renaming, deleting, restoring, exporting, and importing your tab sessions, and keeping automatic snapshots of the current window. There is no server to share it with. The developer does not read the stored sessions.

Limited use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Какие данные обрабатываются

Когда вы сохраняете именованную сессию, оставляете снимок как именованную сессию или когда делается автоматический снимок, расширение читает вкладки только этого окна и записывает:

  • случайный идентификатор сессии или снимка, созданный на этом устройстве (это не идентификатор аккаунта и не идентификатор пользователя)
  • для именованной сессии — имя, не длиннее 200 символов, без невидимых символов и символов смены направления текста
  • URL каждой вкладки в том виде, в каком его сообщает браузер, либо pending URL, если адрес ещё не загрузился
  • заголовок вкладки, не длиннее 300 символов, без тех же невидимых символов; пустой заголовок записывается как «Untitled»
  • признак закрепления
  • позицию вкладки в окне
  • если вкладка входит в группу — локальный идентификатор группы, её имя, цвет и свёрнутость
  • при наличии — положение и размер окна, чтобы восстановление могло открыть окно
  • время сохранения сессии или снимка

Автоматические снимки делаются при закрытии окна и примерно каждые пять минут, если вы не отключили их в настройках. Хранятся пять последних автоматических снимков. Отдельный автоматический снимок можно удалить. «Оставить» копирует снимок в именованную сессию; сам снимок остаётся в автоматическом списке, пока его не вытеснит более новый или пока вы его не удалите. Именованные сессии в эти пять не входят.

Может храниться короткий локальный флаг восстановления, если Chrome закрылся некорректно, чтобы окно расширения или боковая панель предложили восстановить последний снимок. Тема, язык, включены ли автоматические снимки, открывает ли значок на панели инструментов всплывающее окно или боковую панель, и решение отложить или скрыть предложение оценить расширение в магазине тоже хранятся на устройстве.

Историю прежних посещений Chrome расширение не читает и отдельное время визита для каждой страницы не хранит. Текст страницы, cookie, пароли, поля форм и значки сайтов оно не читает.

Адреса со схемами javascript:, data:, vbscript: и blob: отбрасываются и не сохраняются. Это касается и адреса, который становится одной из этих схем только после удаления символов табуляции и перевода строки. Адрес длиннее 32 768 символов не сохраняется. Вкладка без адреса записывается с пустым адресом и не открывается снова. Остальные адреса в окне, включая служебные страницы браузера, сохраняются. При восстановлении расширение открывает адреса http, https и file, сохранённую страницу новой вкладки и about:blank. Любой другой сохранённый адрес остаётся в сессии и не открывается. Страницы вроде chrome:// запоминаются, но снова не открываются.

В URL или заголовке могут быть персональные данные, в том числе страница, на которой вы были подписаны, и токен, который сайт поместил в адрес. Расширение хранит эту строку URL. Оно не извлекает токен из адреса и никуда его не отправляет.

Если в сохранённой сессии есть запрещённый адрес, эта вкладка удаляется из записи. Если запрещены все адреса сессии, сессия удаляется. Две сохранённые сессии с одним идентификатором хранятся как одна.

Новое сохранение или импорт отклоняется, если в новой сессии больше 2000 вкладок или она не помещается в локальное хранилище. Фиксированного лимита числа именованных сессий нет. Уже сохранённая сессия с более чем 2000 вкладками остаётся как есть. Расширение не удаляет сохранённые сессии, чтобы освободить место.

Можно выгрузить JSON-резервную копию сессий и снимков и импортировать этот файл обратно. Можно также импортировать список OneTab или JSON-резервную копию Session Buddy. Импорт читает только выбранный вами файл. Новые сессии добавляются, дубликаты и некорректные записи пропускаются. Ничего не загружается на сервер.

Где хранятся данные

Сессии, снимки и перечисленные настройки хранятся в chrome.storage.local в профиле Chrome. Расширение не использует chrome.storage.sync. Кратковременная копия вкладок каждого открытого окна может также храниться в chrome.storage.session, чтобы при закрытии окна можно было сделать автоматический снимок; Chrome очищает это хранилище в конце сессии браузера. Эти данные не отправляются разработчику и ни на какой другой сервер. В расширении нет аналитики, рекламы и отправки отчётов о сбоях, и его собственный код сетевых запросов не делает.

В версии 1.0.1 ту же библиотеку на устройстве можно открыть в боковой панели Chrome, как во всплывающем окне. Настройка на устройстве выбирает, открывает ли значок на панели инструментов всплывающее окно или боковую панель. Боковая панель ничего никуда не отправляет.

Восстановление сессии просит Chrome открыть сохранённые адреса как обычные вкладки. Дальше страницы загружает сам браузер. Это не загрузка сессии расширением на сервер.

Экспорт записывает JSON-файл на компьютер только по нажатию «Экспорт». Импорт читает файл только когда вы его выбираете. Ни то ни другое файл не отправляет. Если вы потом сами перешлёте этот файл, это происходит вне расширения.

Инкогнито

В режиме инкогнито расширение не работает, пока вы не разрешите его на chrome://extensions. После разрешения инкогнито использует отдельное хранилище (incognito: "split"). Сессия или снимок, сохранённые в окне инкогнито, остаются в этой сессии инкогнито и не копируются в обычный профиль. Chrome удаляет это хранилище, когда сессия инкогнито заканчивается.

Разрешения

  • tabs — читать URL, pending URL, заголовок, признак закрепления, позицию и принадлежность к группе вкладок в окне, которое вы сохраняете или которое автоматически снимается, и снова открывать эти вкладки при восстановлении. Расширение читает вкладки текущего окна при сохранении, при автоматическом снимке и при восстановлении сессии. Скрипты в страницы не внедряются, API истории, cookie и scripting не используются.
  • storage — хранить сессии, снимки и настройки в chrome.storage.local на устройстве. Синхронизируемое хранилище не используется.
  • unlimitedStorage — чтобы библиотека на устройстве не обрезалась на 10 МБ.
  • alarms — снимок окна примерно каждые пять минут.
  • tabGroups — сохранять и восстанавливать имя, цвет, свёрнутость и состав группы вкладок.
  • sidePanel — показывать ту же библиотеку на устройстве в боковой панели Chrome. Локальная настройка выбирает, открывает ли значок на панели инструментов всплывающее окно или боковую панель.

Расширение не запрашивает доступ к сайтам и не запрашивает право выполнять удалённый код. Content script нет. Разрешения sessions, history и downloads не запрашиваются.

Срок хранения

Именованные сессии хранятся, пока вы не удалите их в окне расширения или в боковой панели, или не удалите само расширение. Автоматические снимки хранятся, пока их не вытеснят более новые (хранятся пять последних), пока вы не удалите один из них, или пока вы не удалите расширение. При удалении расширения Chrome стирает его локальное хранилище. Сессии и снимки инкогнито заканчиваются вместе с сессией инкогнито.

Если сохранение или импорт не помещается в локальное хранилище, уже записанные сессии не удаляются, расширение показывает ошибку. Собственный предел в 10 МБ расширение не применяет.

Передача

Разработчик не продаёт эти данные, не передаёт их третьим лицам и не использует их для рекламы, оценки кредитоспособности, кредитования или чего‑либо, кроме сохранения, переименования, удаления, восстановления, экспорта и импорта ваших сессий вкладок и хранения автоматических снимков текущего окна. Сервера, которому их можно передать, нет. Разработчик сохранённые сессии не читает.
