Products

Page Link Status v0.2.1

Check every link on the page you are viewing and see which ones work, redirect, or are broken.

  • One-click scan of all http(s) links on the current tab
  • Statuses: OK, Redirect (with final URL), Broken, Manual, Skip
  • Links outlined in color directly on the page
  • Export results to CSV
  • Runs only when you click Scan; nothing is sent to us
[ ]

Tab Session Manager v0.1.0

Save the tabs of a window as a named session and restore them later in one click.

  • Save, restore, rename and delete sessions
  • Tab count and creation date for each session
  • Export / import sessions as JSON for backup or another computer
  • Minimal permissions: tabs and local storage only
  • All sessions stored locally in your browser
