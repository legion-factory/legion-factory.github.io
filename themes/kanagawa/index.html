Kanagawa by Legion Labs

A Chrome theme: Kanagawa (Wave) colors for the Chrome frame, tabs, toolbar and new tab page. This page itself uses the same palette.

Coming soon to the Chrome Web Store

A theme only: it changes the colors of Chrome itself, not of websites. No permissions, no code, nothing is collected.

Where the palette comes from

Kanagawa is a dark color scheme for Neovim by Tommaso Laurenzi (rebelot), published in 2021 under the MIT license. Its README describes it as “inspired by the colors of the famous painting by Katsushika Hokusai” — The Great Wave off Kanagawa.

It comes in three variants: wave, the default (“heart-warming”), dragon “for those late-night sessions” and lotus, a light variant “for when you're out in the open”. This Chrome theme uses the Wave colors.

Why people use it

The repository has more than 6,000 stars on GitHub. Its README shows a WCAG 2.1 AA contrast badge, extensive Tree-sitter and plugin support, and fast startup by compiling the theme to Lua bytecode.

The project is presented through its GitHub README with a large preview image, and it ships official “extras” — ports for terminals and tools such as Alacritty, Kitty, WezTerm, Ghostty, iTerm, Windows Terminal, Emacs and Fish — so the same colors can be used across a setup.
