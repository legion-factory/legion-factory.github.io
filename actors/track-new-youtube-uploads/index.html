$ legion actor track-new-youtube-uploads

Track new uploads from YouTube channels

A date cutoff turns the channel list into a “what is new” extract, which is the usual input for a weekly competitor or research digest.

Run this example on Apify

Open the youtube-channel-videos actor in the Apify Store

Price: $0.80 per 1,000 videos, Shorts or streams. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://www.youtube.com/@mkbhd",
    "https://www.youtube.com/@veritasium"
  ],
  "oldestPostDate": "30 days",
  "maxResultsPerChannel": 15
}

What this example does not do

This is not a subscription or push alert. Videos older than the date you set are omitted.
