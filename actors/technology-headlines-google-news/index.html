$ legion actor technology-headlines-google-news

Export Google News technology headlines

If you want a snapshot of the Technology topic rather than a keyword search, this run reads that topic feed and writes the headlines to a dataset you can download.

Run this example on Apify

Open the google-news actor in the Apify Store

Price: $1.00 per 1,000 articles. Plus $0.50 per 1,000 resolved publisher URLs. Failed decodes and error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "queries": [],
  "topics": [
    "TECHNOLOGY"
  ],
  "maxArticlesPerQuery": 10,
  "resolveUrls": true,
  "maxUrlResolves": 10
}

What this example does not do

This example does not decode publisher URLs and does not mix in other topics. It is a topic feed, not a full-text news archive.
