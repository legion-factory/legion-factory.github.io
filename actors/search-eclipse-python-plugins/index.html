$ legion actor search-eclipse-python-plugins

Search Eclipse Marketplace for Python plugins

If you are choosing an Eclipse plugin, a keyword search such as python gives you installs, license, latest update and update site for each result in one table.

Run this example on Apify

Open the eclipse-marketplace-plugins actor in the Apify Store

Price: $1.50 per 1,000 plugins. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "query": "python",
  "maxPlugins": 15
}

What this example does not do

This example does not install anything and it does not test whether a plugin works with your Eclipse version. Install counts are as shown by the Marketplace.
