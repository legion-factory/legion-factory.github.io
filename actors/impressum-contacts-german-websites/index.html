$ legion actor impressum-contacts-german-websites

Get contact details from German Impressum pages

German sites usually publish an Impressum. This run starts from the homepage and looks on those legal pages for the public contact details the site already shows.

Run this example on Apify

Open the website-contact-details actor in the Apify Store

Price: $2.00 per 1,000 websites that return contacts. Rows with no contacts or an error are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://www.hellofresh.de",
    "https://www.check24.de",
    "https://www.otto.de"
  ],
  "maxPagesPerSite": 4
}
