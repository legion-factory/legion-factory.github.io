$ legion actor youtube-channel-video-list

Get the video list of a YouTube channel

A channel’s public uploads list is enough to see publishing cadence and which titles found an audience, without clicking through the channel page.

Run this example on Apify

Open the youtube-channel-videos actor in the Apify Store

Price: $0.80 per 1,000 videos, Shorts or streams. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://www.youtube.com/@3blue1brown"
  ],
  "maxResultsPerChannel": 30
}
