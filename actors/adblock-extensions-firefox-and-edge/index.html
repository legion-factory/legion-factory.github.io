Compare adblock extensions on Firefox and Edge

Comparing adblock tools across stores usually means two catalogues. This run searches Firefox Add-ons and Microsoft Edge Add-ons for “adblock” and writes name, users or installs, and rating in one table.

Run this example on Apify

Open the browser-extensions-scraper actor in the Apify Store

{
  "stores": "both",
  "queries": [

What this example does not do

This example does not search the Chrome Web Store, and it does not install or review an extension. It reads the official Firefox and Edge catalogues only.
