$ legion actor greenhouse-jobs-from-company-list

Get Greenhouse jobs from a list of companies

If you already know which companies post on Greenhouse, you can hand the actor a short list of board slugs and get the open roles in one table, instead of opening each career site.

Run this example on Apify

Open the career-site-jobs actor in the Apify Store

Price: $3.00 per 1,000 jobs. Open jobs from Greenhouse, Lever and Ashby career pages. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "companies": [
    "greenhouse:stripe",
    "greenhouse:airbnb"
  ],
  "maxJobsPerCompany": 10,
  "includeDescription": false
}

Sample output

companytitlelocationats
StripeAbuse InvestigatorSeattle, San Francisco, New York Citygreenhouse
StripeAccount Executive, AI SalesSan Francisco, CAgreenhouse
StripeAccount Executive, AI SalesSan Francisco, CAgreenhouse

Sample from a real run of this example. Personal names and email addresses on this page are redacted.

What this example does not do

This example only reads Greenhouse boards (the slugs are prefixed with greenhouse:). It does not include full job descriptions, and it does not search Lever or Ashby.
