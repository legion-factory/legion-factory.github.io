Export residential care homes in the North West

The official CQC England directory is a large monthly spreadsheet. This run keeps residential homes in the North West, with the provider name, postcode and region already in a table.

Run this example on Apify

Open the cqc-england-registry actor in the Apify Store

Price: $4.00 per 1,000 locations. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "region": "North West",
  "serviceType": "Residential homes",
  "maxLocations": 25
}

What this example does not do

This example uses the public monthly directory CSV, not the key-protected CQC API, and it is not a live inspections feed. Registered-manager personal names are not stored.
