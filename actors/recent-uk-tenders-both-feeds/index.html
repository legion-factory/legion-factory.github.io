Watch recent UK tenders from both official feeds

When you follow public contracts in the UK, you usually have to check Contracts Finder and Find a Tender separately. This run reads both official feeds and de-duplicates notices by Open Contracting ID.

Run this example on Apify

Open the uk-tenders-scraper actor in the Apify Store

Price: $3.00 per 1,000 notices. Error rows are not charged. Actor start is $0.00005.

  "publishedFrom": "2026-11-20",
  "maxNotices": 20,
