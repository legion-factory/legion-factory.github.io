$ legion actor emails-phones-from-websites

Extract emails and phone numbers from websites

For a short list of sites, the actor follows a few internal pages (help, contact, about) and writes down the public emails and social links it finds.

Run this example on Apify

Open the website-contact-details actor in the Apify Store

Price: $2.00 per 1,000 websites that return contacts. Rows with no contacts or an error are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://www.python.org",
    "basecamp.com",
    "https://www.mozilla.org"
  ],
  "maxPagesPerSite": 5
}

What this example does not do

You are billed only when a site returns contacts. This page shows redacted addresses. The actor does not log in, bypass forms, or guess unpublished addresses.
