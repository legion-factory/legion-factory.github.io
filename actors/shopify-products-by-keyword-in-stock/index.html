$ legion actor shopify-products-by-keyword-in-stock

Find in-stock Shopify products by keyword

When you only care about a category or a flavour, a keyword plus an in-stock filter keeps the table short.

Run this example on Apify

Open the shopify-products actor in the Apify Store

Price: $0.80 per 1,000 products. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://www.colourpop.com"
  ],
  "keywords": [
    "lip"
  ],
  "onlyAvailable": true,
  "maxProductsPerStore": 20,
  "includeVariants": false
}

What this example does not do

Out-of-stock products are dropped in this example. The keyword is a simple text match, not a semantic search.
