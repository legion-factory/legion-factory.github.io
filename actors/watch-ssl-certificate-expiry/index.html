$ legion actor watch-ssl-certificate-expiry

Watch SSL certificate expiry on a domain list

When you are watching certificate expiry, this run writes validity and days left for each domain, together with the HTTP security headers, in one table.

Run this example on Apify

Open the security-headers-checker actor in the Apify Store

Price: $1.00 per 1,000 domains checked. A target that failed is written with an error and is not charged. Actor start is $0.00005.

Input for this example

{
  "urls": [
    "https://www.python.org",
    "https://github.com",
    "https://www.wikipedia.org"
  ]
}

Sample output

urlsecurityScorehttpsAvailablehttpsRedirectsslValidsslDaysUntilExpiry
https://www.python.org40yesyesyes79
https://github.com90yesyesyes64
https://www.wikipedia.org25yesyesyes36

Sample from a real run of this example. Personal names and email addresses on this page are redacted.

What this example does not do

This example does not renew a certificate, and it does not open a certificate-authority account. It reports public TLS details and HTTP security headers only.
