Find Pfizer Type II Drug Master Files

A holder and type filter turns the official DMF directory into a short supplier list: active Type II files whose holder name contains Pfizer.

Run this example on Apify

Open the fda-drug-master-files-scraper actor in the Apify Store

Price: $2.00 per 1,000 Drug Master Files. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "holder": "PFIZER",
  "status": "A",
  "dmfType": "II",
  "maxRecords": 100
}

What this example does not do

This example does not include confidential DMF contents, and it does not contact the holder. It only keeps public list rows that match the holder, type and status filters.
