$ legion actor bulk-check-http-status-codes

Bulk check HTTP status codes of URLs

A short list of URLs is enough to see which addresses still answer 200 and which have gone missing, which is the usual first step of a link audit.

Run this example on Apify

Open the url-status-checker actor in the Apify Store

Price: $0.10 per 1,000 checked URLs. A request that failed or was blocked is not charged. Actor start is $0.00005.

Input for this example

{
  "urls": [
    "https://example.com",
    "https://www.python.org/",
    "https://github.com/legion-factory-nonexistent-page-404",
    "https://www.wikipedia.org/"
  ]
}

What this example does not do

This is an HTTP-only check, not a JavaScript renderer. A request that fails to connect is not billed. It does not spider a whole site.
