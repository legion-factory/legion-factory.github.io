$ legion actor eclipse-testing-tools-plugins

List Eclipse Marketplace testing tools

To compare testing plugins, a category and market filter lists every Testing plugin in the Tools market with install counts and the update site.

Run this example on Apify

Open the eclipse-marketplace-plugins actor in the Apify Store

Price: $1.50 per 1,000 plugins. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "category": "Testing",
  "market": "Tools",
  "maxPlugins": 25
}

What this example does not do

This example does not rate plugin quality. It lists Marketplace entries with their public numbers, including new plugins that have zero installs.
