$ legion actor export-telegram-channel-posts

Export posts from a public Telegram channel

Public channels can be read without an account. This run writes the recent posts to a table, including view counts when the channel shows them.

Run this example on Apify

Open the telegram-channel-posts actor in the Apify Store

Price: $0.40 per 1,000 posts. error and no_posts rows are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://t.me/telegram"
  ],
  "maxPostsPerChannel": 20,
  "includeChannelInfo": true
}

What this example does not do

Private or login-only channels are out of scope. This example does not collect comments, and it does not download media files.
