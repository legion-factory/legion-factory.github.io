$ legion actor one-star-google-play-reviews

Get 1-star Google Play reviews for app feedback

A 1-star filter is a short way to read the harshest public feedback without scrolling past five-star reviews.

Run this example on Apify

Open the google-play-reviews actor in the Apify Store

Price: $0.10 per 1,000 reviews. no_reviews and error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://play.google.com/store/apps/details?id=com.spotify.music"
  ],
  "sortBy": "newest",
  "rating": 1,
  "language": "en",
  "country": "us",
  "maxReviewsPerApp": 20
}
