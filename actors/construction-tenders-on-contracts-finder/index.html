$ legion actor construction-tenders-on-contracts-finder

Find construction tenders on Contracts Finder

A keyword such as “construction” cuts the official Contracts Finder feed down to the notices you actually want to review, in a short list you can download.

Run this example on Apify

Open the uk-tenders-scraper actor in the Apify Store

Price: $3.00 per 1,000 notices. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "sources": "contracts-finder",
  "publishedFrom": "2026-11-01",
  "keyword": "construction",
  "maxNotices": 50,
  "dedupeByOcid": true
}

What this example does not do

This example reads Contracts Finder only, not Find a Tender. The keyword is applied after the official API returns notices, because the public GET search does not filter by keyword.
