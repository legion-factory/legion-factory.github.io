$ legion actor export-app-store-reviews-csv

Export App Store reviews of an iOS app to CSV

App Store reviews are a straightforward way to read what people write about an app: stars, title, text, version and date, in one download.

Run this example on Apify

Open the app-store-reviews actor in the Apify Store

Price: $0.10 per 1,000 reviews. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://apps.apple.com/us/app/duolingo-language-lessons/id570060128"
  ],
  "maxReviewsPerApp": 30,
  "sortBy": "mostrecent"
}

What this example does not do

Apple’s public feed is capped per country (up to 500 reviews). Reviewer names are redacted in the sample on this page.
