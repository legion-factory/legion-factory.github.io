$ legion actor paracetamol-cep-certificate-holders

Find valid paracetamol CEP certificate holders

When you already know the substance, a name filter such as paracetamol cuts the EDQM database down to the valid certificates and their holders.

Run this example on Apify

Open the edqm-cep-certificates actor in the Apify Store

Price: $1.00 per 1,000 certificates. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "substance": "paracetamol",
  "status": "Valid",
  "maxRecords": 50
}

What this example does not do

This example does not rank suppliers or check GMP status. It lists certificate records that match the substance and status, so you can decide whom to contact.
