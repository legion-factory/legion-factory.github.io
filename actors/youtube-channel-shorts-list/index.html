$ legion actor youtube-channel-shorts-list

List all Shorts of a YouTube channel

If you care about a channel’s short-form output, you can ask the actor for Shorts only and skip the long uploads.

Run this example on Apify

Open the youtube-channel-videos actor in the Apify Store

Price: $0.80 per 1,000 videos, Shorts or streams. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://www.youtube.com/@MrBeast"
  ],
  "contentTypes": [
    "shorts"
  ],
  "maxResultsPerChannel": 20
}

What this example does not do

Regular uploads and live streams are excluded in this example. The actor does not download the Shorts themselves.
