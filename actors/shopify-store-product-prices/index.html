$ legion actor shopify-store-product-prices

Export product prices from a Shopify store

Public Shopify stores expose a product feed. This run turns that feed into a price list you can compare later or load into a sheet.

Run this example on Apify

Open the shopify-products actor in the Apify Store

Price: $0.80 per 1,000 products. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://www.allbirds.com"
  ],
  "maxProductsPerStore": 20,
  "includeVariants": true
}

What this example does not do

This example does not filter by keyword. It does not log in, and it does not read warehouse-level inventory beyond what the store already publishes.
