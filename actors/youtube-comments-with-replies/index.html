Scrape YouTube comments with replies

Threads matter when you are reading a debate or a support section. This run keeps replies attached to the parent comment so you can sort the conversation later.

Run this example on Apify

Open the youtube-comments actor in the Apify Store

Price: $0.50 per 1,000 comments or replies. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
  ],
  "maxCommentsPerVideo": 15,
  "includeReplies": true,
  "maxRepliesPerComment": 5
}
