List valid CEP certificates held by Indian manufacturers

To shortlist active-substance suppliers in India, filter the daily EDQM certificate file by holder country and status, then download the rows as a table.

Run this example on Apify

Open the edqm-cep-certificates actor in the Apify Store

Price: $1.00 per 1,000 certificates. Error rows are not charged. Actor start is $0.00005.

{
  "status": "Valid",
  "country": "IN",
  "maxRecords": 25

What this example does not do

This example does not include the certificate PDFs or the full dossier, and it does not contact the holder. It reads the public EDQM list and keeps the rows that match the country and status filters. Commercial reuse of the data needs attribution to EDQM.
