Export active FDA Drug Master Files

The official quarterly DMF list is a large workbook. This run keeps a short slice of active files: number, type, holder, subject and submit date.

Run this example on Apify

Open the fda-drug-master-files-scraper actor in the Apify Store

Price: $2.00 per 1,000 Drug Master Files. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "status": "A",
  "maxRecords": 25
}

What this example does not do

This example does not filter by holder or DMF type, and it does not download the underlying DMF document. Only the public list fields are stored.
