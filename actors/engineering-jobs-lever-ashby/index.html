$ legion actor engineering-jobs-lever-ashby

Find engineering jobs on Lever and Ashby career pages

When you follow a few companies that hire on Lever or Ashby, a keyword filter such as “engineer” cuts the board down to the roles you actually want to review.

Run this example on Apify

Open the career-site-jobs actor in the Apify Store

Price: $3.00 per 1,000 jobs. Open jobs from Greenhouse, Lever and Ashby career pages. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "companies": [
    "lever:palantir",
    "ashby:openai",
    "ashby:notion"
  ],
  "keywords": [
    "engineer"
  ],
  "maxJobsPerCompany": 10,
  "includeDescription": false
}

Sample from a real run of this example. Personal names and email addresses on this page are redacted.

What this example does not do

This example does not read Greenhouse boards, and it does not download full job descriptions. Roles whose title does not match the keyword are dropped.
