$ legion actor newest-youtube-comments

Monitor the newest comments on a YouTube video

Newest-first is the useful order when you are checking a video after a release or a news spike, rather than reading the all-time most-liked comments.

Run this example on Apify

Open the youtube-comments actor in the Apify Store

Price: $0.50 per 1,000 comments or replies. Error rows are not charged. Actor start is $0.00005.

Input for this example

{
  "startUrls": [
    "https://www.youtube.com/watch?v=aircAruvnKk"
  ],
  "maxCommentsPerVideo": 20,
  "sortBy": "newest",
  "includeReplies": false
}

What this example does not do

This is a single export, not a webhook. Replies are turned off in this example so the table stays on new top-level comments.
